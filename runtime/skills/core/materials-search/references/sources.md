# 材料来源和排序

| 来源 | 内容 | 推荐时的排序指标 |
| --- | --- | --- |
| COD | 已发布实验晶体记录和原始 CIF | 未配置通用数值指标 |
| OQMD | 计算形成能和结构，按组成查找 | 形成能 `delta_e` |
| AFLOW | 计算结构和性质，先查元素再过滤化学计量比 | `enthalpy_formation_atom` |
| Materials Project | 材料摘要、结构与相稳定性字段 | `energy_above_hull` |

排序在各来源内进行，缺指标的记录排最后。CIF 解码或组成检查失败时保留数据库记录，并列出警告。限制按来源计算。AFLOW 的物种查询分页最多四页，空结果时可以单独查其他来源。
